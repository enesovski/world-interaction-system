# Phase 1 Implementation Plan

> **For agentic workers:** Use superpowers:executing-plans to implement this plan inline, task by task.

**Goal:** Deliver a minimal, mouse-testable surface interaction core.

**Architecture:** Retain the existing queued scene manager and channel assets. Rename the responder step to Simulate; keep input, routing, and debug rendering separate.

**Tech Stack:** Unity 6000.3.11f1, C#, URP, Input System, Unity Test Framework.

**Spec:** ../specs/2026-10-16-phase-one-design.md

## Global Constraints

- Work inside Assets/Archura/World Interaction System; preserve existing project changes.
- No additional rendering cameras, simulation shaders, or third-party dependencies.
- Brief comments only; no new singleton or service framework.
- Work in place: the repository has an unborn main branch and existing staged user changes; do not commit or alter staging.

## Review Focus

- Disabling the manager discards pending inputs and rejects later submissions while disabled.
- A responder subscribed to multiple channels simulates only once.
- Callback-generated samples are deferred without being lost or duplicated.
- One throwing responder does not block other responders or poison subsequent frames.
- Debug markers expire and disappear when the responder is disabled.
